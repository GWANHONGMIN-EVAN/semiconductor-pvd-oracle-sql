# Semiconductor PVD Process Quality Analysis

Oracle SQL을 활용하여 반도체 PVD 공정 데이터를 분석하고,
공정 품질 저하와 센서 이상 패턴을 탐색하는 프로젝트

## Project Goal

- Oracle Database 기반 데이터 적재 및 관리
- 반도체 PVD 공정 데이터 분석
- Wafer thickness 및 공정 품질 분석
- SQL을 활용한 이상 공정 탐지
- SQLD에서 학습한 SQL 문법의 실전 적용

## Tech Stack

- Oracle Database
- Oracle SQL Developer
- SQL
- Git
